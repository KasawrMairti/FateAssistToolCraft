# Fate Assist Tool Craft

워크래프트 III 리포지드 대기실 관리 도구의 공식 배포 저장소입니다.

## 다운로드

[최신 Windows x64 버전](https://github.com/KasawrMairti/FateAssistToolCraft/releases/latest)에서 `FateAssistToolCraft_<버전>_Windows_x64.zip`을 받으세요. ZIP의 모든 파일을 같은 폴더에 압축 해제하고 `FateAssistToolCraft.exe`를 실행합니다. Windows용 .NET 10 Desktop Runtime이 필요합니다.

## 자동 업데이트

0.1.40부터 **업데이트** 탭을 제공합니다.

- 실행 시 및 6시간마다 새 정식 버전을 확인하고 자동 다운로드합니다.
- 다운로드 파일의 SHA-256과 패키지 구조를 검사합니다.
- **재시작·업데이트 적용**을 누르면 Fate Tool만 정상 종료한 뒤 업데이트하고 다시 실행합니다.
- 워크래프트는 종료하지 않으며 설정과 유저기록은 유지합니다.
- 교체 대상 파일을 먼저 백업하고, 파일 교체 중 실패하면 복구합니다. 새 버전 실행 후의 기능 오류를 자동으로 감지해 복구하지는 않습니다.

사용자는 GitHub 로그인 없이 공개 릴리스를 다운로드할 수 있습니다. 이 저장소에는 배포 파일과 안내만 게시하며 개인 설정·플레이어 기록·개발 중인 체력바 후킹 시험 코드는 포함하지 않습니다.
